# Dadda_Multiplier_ATPG

**Automatic Test Pattern Generation for a 4-bit Dadda Multiplier**

A **Verilog RTL and digital testing** project demonstrating the complete design-for-testability workflow for a **4-bit Dadda Multiplier**. The project covers RTL implementation, logic synthesis using **Yosys**, and **Automatic Test Pattern Generation (ATPG)** using **Atalanta**, including manual D-Algorithm fault tracing.

## Overview

The design implements a **4×4 Dadda Multiplier**, a parallel multiplier that minimizes the number of half adders and full adders during partial-product reduction. The implementation follows the standard Dadda reduction stages before producing the final 8-bit product through a ripple carry adder.

The project demonstrates a complete testing flow:

- RTL implementation of a 4-bit Dadda Multiplier
- Gate-level synthesis using Yosys
- ATPG using Atalanta's FAN algorithm
- Manual D-Algorithm tracing for stuck-at faults

## Design Architecture

The multiplier follows the standard Dadda multiplication flow:

```text
Partial Product Generation
          ↓
    Dadda Reduction
 (Half & Full Adders)
          ↓
 Final Ripple Carry Adder
          ↓
     8-bit Product
```

## Synthesis using Yosys

The RTL is synthesized into a gate-level netlist using **Yosys**, generating both Verilog and benchmark-ready outputs for downstream ATPG analysis.

## ATPG using Atalanta

The synthesized netlist is converted into a benchmark circuit and analyzed using **Atalanta's FAN algorithm** for single stuck-at fault detection.

### ATPG Results

| Metric | Value |

| Circuit Depth | 14 |
| Fault Coverage | **98.986%** |

## D-Algorithm Tracing

The project includes manual D-Algorithm tracing for the **`pp01` stuck-at-0** fault, demonstrating fault activation, propagation, and justification. The traced result matches the test vector generated by Atalanta.

## Running Atalanta

Run Atalanta with the fault list (`-f`), test output (`-t`), and benchmark netlist (`-v`):

```bash
atalanta -f daddafault.flt -t daddatest.test -v daddabench.bench
```

Generated files:

- **`.bench`** – Gate-level benchmark netlist used by Atalanta.
- **`.test`** – Generated ATPG test patterns and fault-free responses.
- **`.flt`** – Fault report containing detected and redundant stuck-at faults.
